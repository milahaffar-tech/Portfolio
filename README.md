# Mila Haffar — Portfolio

A static site with plain HTML, CSS and a small JavaScript file. There's no build step.

- `index.html` is the home page: hero, story and selected work carousels.
- `mof.html`, `yoca.html` and `reset.html` are the case studies.
- `css/styles.css` holds the design tokens (Modernist system, accent `#7a011d`, Chillax type) and all page styles.
- `js/main.js` runs the carousel arrows and loads the images.
- `images/` is where you add photos. See `images/README.md` for the file names.

## Preview locally

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
