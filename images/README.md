# Images

Every grey box on the site is waiting for an image. Save a `.jpg` in this folder
with the matching name below and it replaces the box automatically. You don't
need to edit any HTML. Images show in black and white to match the design.

To use a `.png` or other format, change the `data-src="images/…"` path for that
box in the HTML file.
